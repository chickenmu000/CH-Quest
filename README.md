# CH-Quest

Paper 1.21.x 용 **NPC 퀘스트 플러그인**입니다. Citizens NPC 를 우클릭해서 퀘스트를 받고, `/q` 로 진행도를 확인한 뒤 클리어하면 보상을 받습니다.
(기존 Skript `rpg_quest.sk` 를 그대로 플러그인으로 옮긴 것입니다.)

## 요구 사항
- Paper 1.21.x / Java 21
- [Citizens](https://citizensnpcs.co/) (NPC 우클릭 퀘스트에 필요 - 없어도 로드는 되지만 NPC 퀘스트를 쓸 수 없습니다)

## 기능
- NPC 우클릭 → 퀘스트 **수락 / 거절** GUI → `/q` 에서 진행도 확인
- 목표 종류 2가지
  - **아이템 가져오기** : 인벤토리에 있는 개수로 판정, 클리어 시 아이템 **회수** 선택 가능
  - **몬스터 처치** : 몹의 **이름**(색코드 제외)에 설정한 글자가 들어 있으면 인정 (예: `핑크 돼지`, `아무` = 아무 몬스터)
- **퀘스트 타입** : 일반(한 번만) / 반복(클리어 후에도 계속 받을 수 있음)
- 선행 퀘스트, 동시에 1개만 진행, 포기(쉬프트+우클릭)
- 클리어 시 **다음 퀘스트 안내**(NPC 이름 포함), 이미 클리어한 NPC 를 우클릭해도 안내
- 수락 / 클리어 **타이틀 연출** (글자가 한 칸씩 금색으로 채워짐)
- 보상은 인벤토리 빈 칸이 부족하면 지급하지 않고 비우고 다시 클리어하도록 안내
- **관리 GUI** : 퀘스트 생성/편집/삭제, NPC 연결, 선행 퀘스트, 보상 설정, 목표 추가/삭제, 타입 전환을 전부 클릭으로 (퀘스트가 많으면 페이지 넘기기). 텍스트 입력은 **모루**로 합니다.
- 오프라인 유저 포함 클리어 기록 초기화

## 명령어
| 명령어 | 설명 | 권한 |
| --- | --- | --- |
| `/q` (`/퀘스트정보`) | 진행중인 퀘스트 확인 / 좌클릭 = 클리어, 쉬프트+우클릭 = 포기 | 모두 |
| `/퀘스트` (`/quest`) | 관리 GUI 열기 | `chquest.admin` |
| `/퀘스트 생성\|삭제\|정보\|NPC연결\|보상 <이름>` | 퀘스트 관리 | `chquest.admin` |
| `/퀘스트 목록` | 퀘스트 목록 | `chquest.admin` |
| `/퀘스트 목표 <이름> 가져오기 <개수> [회수]` | 손에 든 아이템을 목표로 | `chquest.admin` |
| `/퀘스트 목표 <이름> 처치 <몹이름> <마리>` | 몹 이름은 띄어쓰기 가능 | `chquest.admin` |
| `/퀘스트 목표삭제 <이름> <번호>` | 목표 삭제 | `chquest.admin` |
| `/퀘스트 선행 <이름> <선행퀘스트\|없음>` | 선행 퀘스트 | `chquest.admin` |
| `/퀘스트 초기화 <닉네임> [퀘스트]` | 클리어 기록 초기화 (퀘스트 생략 시 진행중 + 전부), 오프라인 가능 | `chquest.admin` |

## 관리 GUI 사용법
1. `/퀘스트` → 별 버튼으로 새 퀘스트 생성 (모루 이름칸에 이름 입력 후 **오른쪽 결과 아이템 클릭**, ESC = 취소)
2. 퀘스트(책)를 클릭하면 편집 화면
   - **NPC 연결** : 클릭 후 NPC 우클릭
   - **선행 퀘스트** : 좌클릭 = 입력 / 우클릭 = 해제
   - **보상 설정** : 보상 GUI 에 아이템을 넣고 닫으면 저장
   - **아이템 가져오기 목표** : 아이템을 커서에 든 채 호퍼 버튼 클릭 → 모루에 `10` 또는 `10 회수`
   - **몬스터 처치 목표** : 검 버튼 클릭 → 모루에 `핑크 돼지 10` (마지막 단어 = 마리 수)
   - **퀘스트 타입** : 클릭할 때마다 일반 ↔ 반복
   - 목표 / 퀘스트 삭제는 **쉬프트+우클릭**

## 데이터 파일
- `plugins/CH-Quest/quests.yml` : 퀘스트 정의
- `plugins/CH-Quest/players.yml` : 유저별 진행도 / 클리어 기록 (30초마다 + 종료 시 저장)
- `plugins/CH-Quest/config.yml` : `max-goals` (퀘스트 하나의 최대 목표 수, 기본 12)

## 빌드
```
mvn package
```
`target/CH-Quest.jar` 를 서버 `plugins/` 에 넣으면 됩니다.

## 참고
- 목표를 추가/삭제하면 그 퀘스트를 진행 중인 유저의 처치 진행도는 초기화됩니다.
- 퀘스트 이름에는 `.` 을 쓸 수 없고, 텍스트 명령어에서는 띄어쓰기를 쓸 수 없습니다.
- 몬스터 처치는 `플레이어가 직접 죽인 몹`만 집계합니다.
